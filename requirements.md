# Project Requirements

## Functional Requirements

1. Users can view available movies.
2. Users can select a movie.
3. Users can select a date and showtime.
4. Users can choose available seats.
5. Users can calculate the total ticket price.
6. Users can confirm their booking.

## Non-Functional Requirements

1. The system should be easy to use.
2. The system should respond quickly.
3. User information should be protected.
4. The system should work on mobile and desktop devices.

## Scope

The project covers movie selection, showtime selection, seat selection, and booking confirmation.
