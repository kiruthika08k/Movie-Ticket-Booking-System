# Movie Ticket Booking System

## Project Overview

The Movie Ticket Booking System allows users to view movies, select showtimes, choose seats, and book movie tickets online.

## Objectives

* Display available movies.
* Allow users to select a date and showtime.
* Enable seat selection.
* Calculate ticket prices.
* Confirm bookings.

## Main Features

* Movie listing
* Date and showtime selection
* Seat selection
* Booking confirmation
* Booking history
