# Sprint Planning – Movie Ticket Booking System

## 1. Project Overview

**Project Name:** Movie Ticket Booking System

**Objective:** To design and develop a simple system that allows users to view movies, select a show date and time, choose seats, and book movie tickets.

**Project Methodology:** Agile Scrum

**Sprint Duration:** 1 week per sprint

## 2. Sprint 1 – Movie Selection and Showtime

**Sprint Goal:** Create the basic movie booking interface and allow users to select a movie, date, and showtime.

### Tasks

* Design the movie ticket booking wireframe using diagrams.net.
* Create the home page layout.
* Display available movies.
* Add movie details such as title and genre.
* Provide date selection.
* Provide showtime selection.

### Deliverables

* Movie selection interface.
* Date and showtime selection interface.
* Wireframe uploaded to the GitHub repository.

### Acceptance Criteria

* Users can view the available movies.
* Users can select a movie.
* Users can choose a date and showtime.
* The interface is simple and easy to understand.

## 3. Sprint 2 – Seat Selection and Booking

**Sprint Goal:** Design the seat selection and ticket booking process.

### Tasks

* Design the seat selection layout.
* Display available and booked seats.
* Allow users to select seats.
* Calculate the total ticket price.
* Add a Book Ticket button.
* Design the booking confirmation screen.

### Deliverables

* Seat selection interface.
* Ticket price summary.
* Booking confirmation interface.

### Acceptance Criteria

* Users can identify available seats.
* Users can select seats.
* The total price is displayed correctly.
* The system displays booking confirmation after a successful booking workflow.

## 5. Definition of Done

A task is considered complete when:

* The task requirements are fulfilled.
* The design or implementation is checked.
* Changes are committed to Git.
* Changes are pushed to GitHub.
* The work is reviewed and accepted.

## 6. Expected Outcome

After completing both sprints, the project will have a planned movie ticket booking workflow covering movie selection, date and showtime selection, seat selection, ticket pricing, and booking confirmation.
